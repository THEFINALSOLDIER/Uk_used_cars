# Uk_used_cars

This project is about predicting the prices of secondhanded cars in the uk using different machine learning regression models.

## Dataset

The dataset used for this project is `used_cars_UK.csv`.

The dataset contains information about houses that can be used to predict their prices.

## Machine Learning Models

Three different regression models were used:

- Multiple Linear Regression
- Polynomial Regression
- Random Forest Regression

## Multiple Linear Regression

Multiple Linear Regression was used to predict uk used cars based on multiple independent variables.

## Polynomial Regression

Polynomial Regression was used to model possible non-linear relationships between the features and car prices.

## Random Forest Regression

Random Forest Regression was used to predict car prices using multiple decision trees and capture more complex relationships in the data.
